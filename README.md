# Auto Ticket Classification using Flow Designer

## Project Overview

This project focuses on automating the classification of support tickets using Flow Designer.

## Project Objective

The main objective is to classify incoming tickets automatically and improve the efficiency of ticket management.

## Project Phases

1. Ideation Phase
2. Requirement Analysis
3. Project Design Phase
4. Project Planning
5. Project Development
6. Project Documentation
7. Project Demonstration

## Technologies Used

- ServiceNow
- Flow Designer
- Automation Tools

## Project Outcome

The system helps automate ticket classification and improves the overall ticket management process.
